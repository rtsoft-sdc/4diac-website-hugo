We are pleased to announce the release of **OpenFB**, a new open-source **IEC 61499** runtime for Python. The project source code is available on GitHub: [rtsoft-sdc/OpenFB](https://github.com/rtsoft-sdc/OpenFB).

**OpenFB** is a Python-powered runtime that executes IEC 61499 function block networks designed in the **Eclipse 4diac™ IDE**. It acts as a lightweight, portable execution device — similar in role to FORTE — but written in Python, which makes it particularly attractive for:

- Rapid prototyping of distributed 61499 applications
- Edge devices and embedded Linux platforms
- Research, education, and integration with AI/ML applications
- Industrial automation projects that need easy extension with custom function blocks

By consuming the same `.fbt` libraries and deployment artifacts produced by **4diac IDE**, OpenFB enables engineers to design control logic graphically in 4diac and then deploy it to OpenFB-powered devices without leaving the IEC 61499 toolchain.

The project is a reworked and significantly expanded implementation of the concepts behind DYNASORE. While inspired by DYNASORE, the codebase and architecture have been **almost completely re-engineered**; the new features and changes make it a standalone product focused on integration with latest releases of 4Diac IDE.
## Highlights OpenFB:

- **Supports 4diac IDE 3.1** — native support for the current editor version.
- **OPC UA server embedded**. It is now possible to edit input values using an OPC UA client — useful for testing and runtime tuning.
- Added new feature of exposing inputs/outputs (communication protocol extension).
- The standard library has been extended in accordance with the library of 4diac IDE.
- Fixed issues with older Python 3 versions.
## Highlights 4diac IDE:

OpenFB is fully aligned with the **4diac IDE 3.1** workflow:

- It speaks the same deployment protocol used by 4diac IDE
- It supports the **standard 4diac function block library**
- Applications designed, debugged, and monitored in 4diac IDE can be executed directly on an OpenFB runtime instance
### Path Toward O-PAS Compatibility:

OpenFB is being developed with the long-term goal of supporting the **Open Process Automation Standard (O-PAS™)** of The Open Group. With its embedded **OPC UA** server, simple way to develop User Defined Function Block (UDFB), and IEC 61499 runtime, OpenFB is well positioned to become a building block for **O-PAS-compliant DCNs (Distributed Control Nodes)**.
